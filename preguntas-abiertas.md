# Preguntas abiertas

No quedan preguntas abiertas para el alcance simulado. Las siguientes decisiones son supuestos documentados, no validaciones de una política municipal real:

| Prioridad | Duda | Regla afectada | Impacto | Resolución para esta entrega |
|---|---|---|---|---|
| Cerrada | ¿Cuál es el horario de atención? | RN06, RN07 | Disponibilidad y selección del turno. | Lunes a viernes, 09:00–17:00, bloques de 30 minutos. |
| Cerrada | ¿Con cuánta anticipación se puede cancelar? | RN10 | Libera o no el turno. | Hasta 24 horas antes, inclusive. |
| Cerrada | ¿Se permite duplicar una gestión? | RN09 | Puede duplicar reservas activas. | Una solicitud activa por persona y tipo. |
| Cerrada | ¿Qué datos se conservan para la demo? | RN01, RN12 | Riesgo de privacidad. | Usar exclusivamente datos ficticios; no importar clientes del SQL anterior. |
| Cerrada | ¿Qué políticas reales aplica el municipio? | Alcance | Impide tratar la demo como un servicio oficial. | No se afirma compatibilidad con ninguna jurisdicción real. |
| Externa | ¿Qué URL pública y qué cuentas de hosting se usarán? | Publicación | Sin cuentas/credenciales no se puede desplegar ni verificar desde internet. | La propietaria del proyecto debe conectar sus servicios y compartir la URL resultante para la revisión final. |
